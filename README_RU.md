# 🎵 Музыкальная плита для Roblox

Интерактивная музыкальная плита из кубиков, которые реагируют на громкость музыки и создают красивые волновые эффекты.

## 📋 Возможности

### Базовая версия (`MusicPlate.lua`)
- ✅ Плита 20x20 кубиков
- ✅ Волновые эффекты на основе музыки
- ✅ Динамическое изменение цвета
- ✅ Световые эффекты
- ✅ Простое управление через Command Bar

### Продвинутая версия (`AdvancedMusicPlate.lua`)
- ✅ Плита 25x25 кубиков с улучшенными материалами
- ✅ Симуляция частотного анализа (бас, средние, высокие частоты)
- ✅ Система частиц с динамическими эффектами
- ✅ Сложные волновые паттерны
- ✅ Реверберация и эквалайзер
- ✅ Расширенные настройки

## 🚀 Установка

### Способ 1: Через Roblox Studio Command Bar

1. Откройте **Roblox Studio**
2. Создайте новое место или откройте существующее
3. Откройте **Command Bar** (View → Command Bar)
4. Скопируйте один из скриптов:

**Для базовой версии:**
```lua
-- Скопируйте весь код из MusicPlate.lua и вставьте в Command Bar
```

**Для продвинутой версии:**
```lua
-- Скопируйте весь код из AdvancedMusicPlate.lua и вставьте в Command Bar
```

5. Нажмите **Enter** для выполнения

### Способ 2: Через ServerScriptService

1. В **Explorer** найдите **ServerScriptService**
2. Создайте новый **Script**
3. Скопируйте код из файла и вставьте в скрипт
4. Запустите игру

## 🎮 Управление

### Команды для базовой версии:

```lua
startMusic()              -- Запустить музыку и эффекты
stopMusic()               -- Остановить музыку
destroyPlate()           -- Удалить плиту
setWaveSpeed(число)      -- Установить скорость волн (по умолчанию: 2)
setMaxHeight(число)      -- Установить максимальную высоту (по умолчанию: 10)
changeMusicId(новый_id)  -- Изменить музыку
```

### Команды для продвинутой версии:

```lua
startAdvancedMusic()        -- Запустить с полными эффектами
stopAdvancedMusic()         -- Остановить музыку
destroyAdvancedPlate()     -- Удалить плиту
setAdvancedWaveSpeed(число) -- Скорость волн (по умолчанию: 3)
setAdvancedHeight(число)    -- Максимальная высота (по умолчанию: 15)
changeAdvancedMusic(id)     -- Изменить музыку
```

## 🎵 Музыка

## 🎨 Настройка эффектов

### Параметры базовой версии:

```lua
-- Размер плиты
PLATE_SIZE = 20

-- Размер кубиков
CUBE_SIZE = Vector3.new(4, 1, 4)

-- Скорость волн
WAVE_SPEED = 2

-- Максимальная высота
MAX_HEIGHT = 10
```

### Параметры продвинутой версии:

```lua
-- Конфигурация в CONFIG таблице
PLATE_SIZE = 25           -- Размер плиты
CUBE_SIZE = Vector3.new(3, 1, 3)  -- Размер кубиков
WAVE_SPEED = 3           -- Скорость волн
MAX_HEIGHT = 15          -- Максимальная высота
MIN_HEIGHT = -2          -- Минимальная высота
FREQUENCY_BANDS = 8      -- Частотные полосы
PARTICLE_COUNT = 50      -- Количество частиц
```

## 🔧 Устранение неполадок

### Плита не создается:
- Убедитесь, что вы в **Roblox Studio**, а не в игре
- Проверьте, что **Command Bar** открыт
- Попробуйте перезапустить Studio

### Музыка не играет:
- Проверьте правильность ID музыки
- Убедитесь, что аудио не заблокировано
- Попробуйте другой трек

### Низкая производительность:
- Уменьшите `PLATE_SIZE`
- Снизьте `PARTICLE_COUNT` (только для продвинутой версии)
- Уменьшите `WAVE_SPEED`

### Эффекты работают неправильно:
- Убедитесь, что вы вызвали `startMusic()` или `startAdvancedMusic()`
- Проверьте консоль на ошибки
- Попробуйте пересоздать плиту: `destroyPlate()` → скопируйте код заново
