# Audio Wave Plate для Roblox

Интерактивная плита из кубиков, которая реагирует на громкость музыки и создает волновые эффекты.

## Особенности

- 🎵 Реакция на громкость музыки
- 🌊 Волновые эффекты
- 🎨 Динамическое изменение цветов
- 🎮 Управление через команды в чате
- 📊 Анализ аудио частот

## Установка

1. Откройте Roblox Studio
2. Создайте новый скрипт в `ServerScriptService`
3. Скопируйте содержимое файла `AudioWavePlate.lua`
4. Вставьте код в скрипт
5. Замените `"YourUsername"` на ваше имя пользователя в строке 108

## Команды управления

Используйте эти команды в чате для управления плитой:

- `/play` - запустить музыку
- `/stop` - остановить музыку  
- `/volume [0-1]` - установить громкость (например: `/volume 0.8`)
- `/speed [число]` - установить скорость волн (например: `/speed 3`)
- `/height [число]` - установить максимальную высоту (например: `/height 8`)
- `/help` - показать список команд

## Настройки

Вы можете изменить параметры в начале скрипта:

```lua
local PLATE_SIZE = 20 -- Размер плиты (20x20 кубиков)
local CUBE_SIZE = 2 -- Размер каждого кубика
local WAVE_SPEED = 2 -- Скорость волн
local MAX_HEIGHT = 5 -- Максимальная высота подъема кубиков
local MUSIC_ID = 122400781295647 -- ID вашей музыки
```

## Как это работает

1. **Создание плиты**: Скрипт создает основную плиту и массив из 400 кубиков (20x20)
2. **Анализ аудио**: Система отслеживает громкость музыки и создает волновые паттерны
3. **Волновые эффекты**: Каждый кубик движется вверх и вниз в зависимости от:
   - Расстояния от центра плиты
   - Текущей громкости музыки
   - Времени (для создания волн)
4. **Цветовые эффекты**: Цвет кубиков меняется в зависимости от их высоты

## Дополнительные возможности

Для более продвинутого анализа аудио используйте файл `AdvancedAudioAnalyzer.lua`. Он предоставляет:

- Анализ баса и высоких частот
- История громкости
- Пиковая громкость
- Цветовые схемы на основе частот

## Советы

1. **Производительность**: Уменьшите `PLATE_SIZE` если у вас низкая производительность
2. **Визуальные эффекты**: Увеличьте `MAX_HEIGHT` для более драматичных эффектов
3. **Скорость**: Настройте `WAVE_SPEED` под темп вашей музыки
4. **Цвета**: Измените цвета в коде для создания уникальных эффектов

## Устранение неполадок

- **Музыка не воспроизводится**: Проверьте правильность ID музыки
- **Команды не работают**: Убедитесь, что вы заменили `"YourUsername"` на ваше имя
- **Низкая производительность**: Уменьшите размер плиты или количество кубиков
